# 关注画像

Analyst 判断"值不值得关注"的唯一依据。随时修改此文件即可调整 Argus 的口味。

## 高优先级

- **AI 落地与生产实践**（最优先）：LLM 在真实业务中的应用案例与踩坑复盘、评估（evals）方法、RAG/结构化输出的工程实践、AI 产品化经验、提示词与上下文工程的实战技巧。"怎么把 AI 用起来"比"AI 又有什么新概念"更重要。
- **AI 模型与研究动态**：新模型发布与能力突破（OpenAI / Anthropic / Google / Meta / 开源模型）、重要论文与技术路线之争、各家实验室动向。
- **AI 工程与 agent 开发**：agent 框架与运行时、编码 agent、MCP / skills 等工具生态。

## 常规关注

- **开源项目与开发者工具**：值得关注的新项目、主流语言与框架的重要版本、开发工具链变化。
- **科技行业商业新闻**：大厂战略动向、重要融资并购、AI 相关监管与政策、行业格局变化。

## 不关心

- 消费电子导购、促销、开箱评测
- 游戏与娱乐八卦
- 与科技无关的一般社会新闻
- 蹭 AI 热点但没有实质内容的营销文

## 判断口径

- 同一件事的多方报道要合并成一个事件，别拆散。
- 中文源里的"编译转载"如果对应已有的英文源事件，归入同一事件。
- 评分 9-10 预留给真正的大事（重量级模型发布、行业格局级变化），一周最多出现一两次。
